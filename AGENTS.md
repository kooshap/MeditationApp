# Meditate (iOS)

Minimal offline meditation timer. SwiftUI + @Observable, iOS 17+, iPhone-only, portrait, dark-only.
No dependencies, no tests. See README.md for architecture.

## Build & verify

```bash
xcodebuild -project MeditationApp.xcodeproj -scheme MeditationApp -destination 'generic/platform=iOS Simulator' build
```

Verify UI changes by running in the simulator; there is no test suite.

## Rules

- Fully offline: no network calls, analytics, or third-party packages. PRIVACY.md and
  PrivacyInfo.xcprivacy promise this; update them if data or API usage changes.
- SessionSettings is saved as JSON in UserDefaults. Renaming or removing a field
  needs a migration in init(from:), or existing users silently lose their settings.
- Timer: derive remaining time from sessionEndDate; never count ticks. Don't pause on
  audio interruptions. Don't add the audio background mode (removed for App Review).
- Bells are CAF files generated by scripts/generate_bells.py. Regenerate them; don't
  hand-edit. They must stay CAF because notification sounds can't use MP3.
- project.yml and project.pbxproj are both committed; keep build settings in sync in both.
- When user-facing behavior changes, update README.md and AppStore/listing.md.

## Git

Conventional commits (feat/fix/docs/chore). Build bumps are their own commit:
"chore: bump build number to N for TestFlight" (CURRENT_PROJECT_VERSION in both project files).
